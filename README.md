# Translator Frontend

Le sous-projet frontend de l'application **Translator**, un outil de traduction en ligne rapide, accessible et moderne.

---

## Présentation

**Translator** est une application web de traduction conçue pour offrir une expérience fluide grâce à une interface *glassmorphic* moderne. Le projet est actuellement en phase de développement actif.

### État du projet
- **Intégration UI / HTML & CSS** : Terminée (layout responsive, mode sombre/clair, accessibilité et optimisation SEO).
- **Interactions JS / Logique client** : En cours de développement.
- **Liaison API / Backend** : En cours de développement.

---

## Technologies utilisées

- **Vite** : Bundler rapide et environnement de développement frontend.
- **TypeScript** : Langage typé pour une meilleure robustesse du code.
- **Tailwind CSS & DaisyUI** : Frameworks CSS pour un design responsive et personnalisable.
- **Google Material Symbols** : Jeu d'icônes pour l'interface utilisateur.

---

## Pre-requis

Assurez-vous d'avoir installé [Node.js](https://nodejs.org/) (version 18 ou supérieure) ainsi que votre gestionnaire de paquets préféré (`npm` ou `pnpm`).

---
